    演習：rfft と irfft で雑音を除く

    サンプリング周波数 \(f_s=64\) Hz で \(N=64\) 点（\(T=1\) s）測った信号 \(x_n\) のデータを示す。いくつかの周波数の正弦波と余弦波の和に、ランダムな雑音が加わっている。次のコードを貼り付けて使え。

    import numpy as np

fs = 64.0                     # サンプリング周波数 [Hz]
x = np.array([                # N = 64 点（T = 1 s）
     1.10,  1.78,  2.08,  1.02, -0.36, -0.20, -0.51, -0.55,
    -1.54, -1.27, -1.03,  0.03,  0.16,  0.09, -1.15, -0.53,
    -1.57,  0.23,  0.81,  1.16,  1.16,  0.88,  1.09,  0.96,
     1.22, -0.38, -0.52, -1.04, -0.18, -0.48,  0.15, -0.30,
    -1.75, -1.54, -1.53, -0.52,  0.16, -0.10,  0.08,  0.54,
     1.29,  1.60,  0.89,  0.26, -0.30, -0.11,  0.63,  1.17,
     1.62, -0.05, -1.00, -1.29, -1.64, -1.19, -0.98, -0.76,
    -1.17,  0.24,  0.41,  0.82,  0.66,  0.04,  0.06,  0.42,
])

    (a) rfft で \(a_k\), \(b_k\) を求め、周波数 \(f_k\) に対して図示せよ。振幅の大きい成分の周波数と、その \(a_k\), \(b_k\) を読み取れ。

    (b) 振幅 \(\sqrt{a_k^2+b_k^2}\) の小さい成分を \(0\) にして（閾値は (a) の図から決める）、irfft で波形に戻せ。元の \(x_n\) と重ねて図示し、雑音が除けたか確かめよ。

    ヒント
    • 周波数軸は np.fft.rfftfreq(N, 1/fs)。\(T=1\) s なので \(f_k=k\) Hz になる。
    • \(a_k=2\,\mathrm{Re}\,X_k/N\), \(b_k=-2\,\mathrm{Im}\,X_k/N\)。図は plt.stem(freq, a) で描ける。
    • 雑音は全ての \(k\) に小さく散らばり、信号は少数の \(k\) に大きく出る。閾値はその間に取る。
    • np.where(A >= thr, a, 0.0) で小さい成分を \(0\) にできる。戻すときは \(X_k=\frac{N}{2}(a_k-ib_k)\) を np.fft.irfft(X, n=N) に渡す。
