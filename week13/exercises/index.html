    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    AI の利用について

    演習のコードは AI（ChatGPT・Claude・Gemini など）に書かせてよい。ただし 生成されたコードは全ての行に目を通し、各ステップが何をしているのかを理解すること。講義の最後に演習の時間が取れた回に、自分のコードを解説してくれた人はプラス評価する。理解せずに提出したコードは自分の力にならない。

    環境

    Python（numpy, scipy, matplotlib）を使う。今回は numpy.linalg（svd, pinv, lstsq, cond, matrix_rank）が主役である。scikit-learn は使わない ── PCA も自分で組み立てる。環境は第1回の Google Colab または ローカル環境 を参照。

    演習1（基礎）：SVD の性質と低ランク近似

    (a) 行列

    \[ A=\begin{pmatrix}3&0\\4&5\end{pmatrix} \]

    の特異値分解を 手計算 で求めよ。\(A^\top A\) の固有値・固有ベクトルから \(\sigma_i\) と \(v_i\) を出し、\(u_i=Av_i/\sigma_i\) で \(u_i\) を求める。\(U\) が直交すること、\(|\det A|=\sigma_1\sigma_2\) が成り立つことを確かめ、np.linalg.svd の結果と比べよ（符号が違ってもよい理由を説明すること）。

    (b) 特異値の減り方が違う \(3\) 種類の \(80\times50\) 行列 ── 乱数行列、特異値が指数的に減る行列、階数 \(5\) の行列 ── を作り、階数 \(k=1,5,10,20\) の近似の相対誤差 \(\lVert A-A_k\rVert_F/\lVert A\rVert_F\) を比べよ。また \(\lVert A-A_k\rVert_2=\sigma_{k+1}\) が成り立つことを数値で確かめよ。

    (c) (a) の \(A\) について、単位円の像の最大・最小半径が \(\sigma_1,\sigma_2\) に一致することを数値で確かめよ。さらに、\(Ax=b\) の右辺を \(b\to b+\delta b\) と摂動したときの相対誤差の増幅率が、\(b\) と \(\delta b\) の向きによって \(1/\kappa\) から \(\kappa\)（\(\kappa(A)=\sigma_1/\sigma_2\)）の範囲で変わることを数値で示せ。\(b,\delta b\) を \(u_1,u_2\) 方向にとった \(4\) 通りと、無作為な向きを多数試した場合の両方で確かめること。

    ヒント
    • (a) \(A^\top A=\begin{pmatrix}25&20\\20&25\end{pmatrix}\) になる。\(\begin{pmatrix}a&b\\b&a\end{pmatrix}\) の固有ベクトルは必ず \((1,1)\) と \((1,-1)\) で、固有値は \(a\pm b\) である。\(\sqrt{45}=3\sqrt5\)。
    • (b) 特異値を指定した行列は、直交行列 \(U_0,V_0\) を np.linalg.qr で作り、\(U_0\,\mathrm{diag}(\sigma)\,V_0^\top\) と組み立てれば得られる。指数的に減らすには \(i=1,\dots,n\) に対して \(\sigma_i=10^{-0.15(i-1)}\)（コードでは 10.0**(-0.15*np.arange(n))）とすればよい。階数 \(5\) の行列は先頭 \(5\) 列だけを使う。
    • (c) 増幅率は \(\dfrac{\lVert\delta x\rVert/\lVert x\rVert}{\lVert\delta b\rVert/\lVert b\rVert}\) である。\(A^{-1}=V\Sigma^{-1}U^\top\) なので、\(\delta b\) が \(u_i\) 方向なら \(\lVert\delta x\rVert=\lVert\delta b\rVert/\sigma_i\)、\(b\) が \(u_j\) 方向なら \(\lVert x\rVert=\lVert b\rVert/\sigma_j\) になる。増幅率は \(\sigma_j/\sigma_i\) で、\(4\) 通りの組み合わせから範囲が読める。

    演習2（基礎）：画像の低ランク圧縮

    グレースケール画像を行列とみなし、低ランク近似の効果を定量化する。画像は scipy.datasets.ascent()（\(512\times512\)）を使い、取得できない環境では本文と同じ手続き生成画像で代用してよい。

    (a) 画像の特異値スペクトルと累積エネルギーを計算し、累積エネルギーが \(90\%,95\%,99\%,99.9\%\) になる最小の階数 \(k\) と、そのときの圧縮率 \(k(m+n+1)/(mn)\) を求めよ。

    (b) \(k=1,5,10,20,50,100,200\) の再構成画像を作り、圧縮率・相対誤差・PSNR を表にせよ。再構成画像を並べて描き、どの \(k\) から何が見えるようになるかを述べよ。

    (c) 画像の 行を無作為に並べ替えて から SVD をとると、特異値はどうなるか。まず理由を考えて予想し、それから数値で確かめよ。次に 画素を画像全体で無作為に並べ替えた 場合を同じように調べ、\(2\) つの結果の違いが何を意味するかを説明せよ。

    ヒント
    • (a) 累積エネルギーは cum = np.cumsum(S**2)/(S**2).sum()。しきい値を超える最初の位置は np.searchsorted(cum, e) で求まる（\(0\) 始まりなので \(+1\) する）。
    • (b) PSNR は \(10\log_{10}(255^2/\mathrm{MSE})\)。画像の表示は plt.imshow(Ak, cmap="gray") に vmin=0, vmax=255 を付けると明るさの基準がそろう。
    • (c) 行の並べ替えは、置換行列 \(P\) を左から掛ける操作 \(PA\) である。\(P\) はどんな性質を持つ行列か。一方、画素の総入れ替えは \(PAQ\) の形に書けるか考えてみよ。

    演習3（応用）：PCA による次元削減

    \(8\) 個のセンサが、\(2\) つの潜在信号の線形結合に雑音を加えたものを観測している、という状況を作って PCA を試す。

    rng = np.random.default_rng(5)
N, p = 500, 8
t = np.linspace(0, 10, N)
Z = np.column_stack([np.sin(2*np.pi*0.7*t),
                     np.sign(np.cos(2*np.pi*0.3*t))])
W = rng.normal(0, 1, (2, p))
W /= np.linalg.norm(W, axis=0)
X = Z @ W + rng.normal(0, 0.3, (N, p))

    (a) \(X\) を中心化して SVD をかけ、寄与率と累積寄与率を求めよ。潜在次元が \(2\) であることがスペクトルから読み取れるか。また階数 \(k=1,2,3,4\) の再構成の相対誤差が \(\sqrt{1-（累積寄与率）}\) に一致することを確かめよ。

    (b) 上位 \(2\) 主成分の張る部分空間が、真の部分空間（\(W\) の行が張る \(2\) 次元部分空間）とどれだけ一致しているかを 主角（principal angle） で測れ。さらに雑音の標準偏差を \(0.1,0.3,1.0,3.0\) と変えて、累積寄与率と主角がどう劣化するかを調べよ。

    (c) \(1\) 番目のセンサだけ単位を変えて値を \(100\) 倍したとき、PCA の結果はどう変わるか。累積寄与率・第 \(1\) 主成分・潜在信号の説明力（上位 \(2\) 主成分の得点で \(Z\) を最小二乗当てはめしたときの決定係数 \(R^2\)）の \(3\) つで比べ、標準化（各列を標準偏差で割る）が何を直すのかを述べよ。

    ヒント
    • (a) 相対誤差と累積寄与率の関係は Eckart–Young から出る。\(\lVert X_c-X_k\rVert_F^2=\sum_{i>k}\sigma_i^2\) を \(\lVert X_c\rVert_F^2=\sum_i\sigma_i^2\) で割ればよい。
    • (b) \(2\) つの部分空間の正規直交基底を \(V_2\)（\(2\times p\)）と \(Q\)（\(p\times2\)）とすると、\(V_2Q\) の特異値が主角の余弦になる。\(Q\) は np.linalg.qr(W.T) で得られる。角度は np.degrees(np.arccos(...))。
    • (c) \(R^2\) は、得点行列 \(T=X_cV_2^\top\) で \(Z\) を最小二乗当てはめして \(1-\lVert Z-T\hat c\rVert^2/\lVert Z\rVert^2\)（列ごと）で計算する。\(Z\) も中心化しておくこと。
