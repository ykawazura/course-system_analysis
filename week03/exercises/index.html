    演習1（基礎）：矩形パルスのフーリエ変換

    幅 \(2a\)・高さ \(1\) の 矩形パルス \(f(t)=1\ (\lvert t\rvert<a),\ 0\ (\text{otherwise})\) を考える。

    (a) フーリエ変換 \(F(\omega)=\displaystyle\int_{-\infty}^{\infty} f(t)e^{-i\omega t}dt\) を手計算で求めよ。また \(F(0)\) がパルスの面積に等しいことを示せ。

    (b) \(a=1\) として、\(F(\omega)\) を数値積分（台形則）で計算し、(a) の解析解 \(2\sin\omega a/\omega\) と一致することを確かめよ。

    (c) \(a\) を \(2\) 倍にすると \(F(\omega)\) の幅（最初の零点の位置）はどうなるか。スケーリング則と結びつけて説明せよ。

    ヒント
    • \(\displaystyle\int_{-a}^{a} e^{-i\omega t}dt=\left[\frac{e^{-i\omega t}}{-i\omega}\right]_{-a}^{a}\) を計算し、\(e^{i\theta}-e^{-i\theta}=2i\sin\theta\) を使う。
    • \(\omega\to 0\) では \(\sin\omega a/\omega\to a\)。
    • 数値積分は np.trapezoid(f * np.exp(-1j*w*t), t) の実部を取る。\(t\) は十分広く・細かく取ること。
    • 最初の零点は \(\omega a=\pi\)、すなわち \(\omega=\pi/a\)。

    演習2（基礎）：FFT による振幅スペクトル

    サンプリング周波数 \(f_s=200\) Hz、観測時間 \(T=2\) s で、信号

    \[ x(t)=2\sin(2\pi\cdot 7t)+1.5\sin(2\pi\cdot 20t) \]

    を標本化する。

    (a) numpy.fft.rfft で振幅スペクトルを求め、ピークの 周波数と振幅 を読み取れ。合成に使った値と一致するか確かめよ。

    (b) この設定の 周波数分解能 \(\Delta f=f_s/N\) を求めよ。

    (c) 観測時間 \(T\) を \(0.5\) s に縮めると分解能はどう変わるか。\(7\) Hz と \(7.5\) Hz を分離するには \(T\) を何秒以上にすればよいか述べよ。

    ヒント
    • サンプル数 \(N=f_s T\)。時間軸は t = np.arange(N) / fs。
    • 片側振幅は 2 * np.abs(np.fft.rfft(x)) / N、周波数軸は np.fft.rfftfreq(N, 1/fs)。
    • 分解能 \(\Delta f=f_s/N=1/T\)。2つの周波数を分けるには、\(\Delta f\) をその差 以下（\(\le\)）にするのが目安（厳密には窓関数の主ローブ幅にも依存する）。

    演習3（応用）：エイリアシングとナイキスト周波数

    \(f_0=18\) Hz の余弦波 \(x(t)=\cos(2\pi\cdot 18\,t)\) を \(f_s=20\) Hz で標本化する。

    (a) 見かけの周波数 \(f_{\text{alias}}=\lvert f_0-\mathrm{round}(f_0/f_s)f_s\rvert\) を求め、標本列が \(f_{\text{alias}}\) の余弦波の標本列と一致することを Python で確かめよ。

    (b) \(f_s=20\) Hz では、\(18\) Hz の他にどの周波数が同じ標本列（見かけ \(2\) Hz）になるか。\(50\) Hz 以下で列挙せよ。

    (c) \(18\) Hz の信号を正しく測る（エイリアシングを起こさない）には、\(f_s\) を何 Hz より大きくすればよいか。

    ヒント
    • \(f_0/f_s=0.9\to\mathrm{round}=1\) なので \(f_{\text{alias}}=\lvert 18-20\rvert=2\) Hz。
    • 余弦は偶関数なので、\(\cos(2\pi f n/f_s)\) は \(f\to \lvert{\pm}f+kf_s\rvert\) で不変。
    • 標本化定理より \(f_s>2f_{\max}\)。

    演習4（発展）：高速畳み込みと巡回畳み込み

    (a) 長さ \(1500\) と \(600\) の乱数信号 a, b（rng = np.random.default_rng(7)）について、np.convolve(a, b) と scipy.signal.fftconvolve(a, b) が一致することを確かめよ。線形畳み込みの 長さ はいくつになるか。

    (b) 長さ \(6\) の信号 a, b（rng = np.random.default_rng(8)）について、同じ長さ \(6\) のまま FFT の積をとった 巡回畳み込み が np.convolve（線形畳み込み）と一致しない理由を述べ、ゼロ詰め で一致させる方法を示せ。

    (c) 直接法と FFT 法の計算量はそれぞれ何か。\(N\) が大きいときどちらが有利か。

    ヒント
    • 一致は np.max(np.abs(np.convolve(a,b) - ss.fftconvolve(a,b)))。
    • 線形畳み込みの長さは \(N+M-1\)。
    • 巡回畳み込み：np.fft.irfft(np.fft.rfft(a)*np.fft.rfft(b), n=6)。ゼロ詰めは rfft(a, L) で長さ L=N+M-1。
    • DFT は信号が周期的に繰り返すとみなす → 端が折り返す。

    演習5（発展）：相互相関による遅延推定

    ある信号 base（rng = np.random.default_rng(9)、長さ \(N=5000\)、\(f_s=2000\) Hz）が、未知の遅延だけ遅れ、さらに雑音を受けて

    \[ y[n]=\text{base}[n-\tau]+0.6\,\varepsilon[n], \qquad \text{base}[k]=0\ (k<0) \]

    として観測された（真の遅延 \(\tau=87\) サンプル）。第2項の \(\varepsilon\) は標準正規乱数である。\(n<\tau\) では base の添字が負になるので、上のようにゼロで延長すると約束する（コードの y = np.zeros(N); y[tau:] = base[:N-tau] がこれにあたる）。

    (a) scipy.signal.correlate（method='fft'）で y と base の相互相関を求め、ピーク位置から遅延 \(\tau\) を推定せよ。何ミリ秒に相当するか。

    (b) 雑音が信号と同程度でもピークが立つのはなぜか。相互相関が遅延検出に強い理由を述べよ。

    (c) この技術が使われる実例を1つ挙げよ。

    ヒント
    • 遅延信号は y = np.zeros(N); y[tau:] = base[:N-tau] に雑音を加える。
    • 相互相関とラグは ss.correlate(y, base, method='fft') と ss.correlation_lags(N, N)。
    • 推定遅延は lags[np.argmax(corr)]。時間は \(\tau/f_s\)。
