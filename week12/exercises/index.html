    演習1（基礎）：直交性の確認と Legendre 展開

    区間 \([-1,1]\)、重み \(w(x)=1\) の内積 \(\langle f,g\rangle=\int_{-1}^{1}fg\,dx\) を使う。

    (a) 単項式 \(1,\ x,\ x^2,\ x^3\) に Gram–Schmidt の直交化を 手計算 で施し、得られる 4 つの多項式 \(q_0,\dots,q_3\) を求めよ。またそれらが Legendre 多項式 \(P_0=1\)、\(P_1=x\)、\(P_2=\frac{1}{2}(3x^2-1)\)、\(P_3=\frac{1}{2}(5x^3-3x)\) の定数倍になっていることを確かめよ。

    (b) \(k\le8\) の Legendre 多項式について、グラム行列 \(G_{mn}=\int_{-1}^{1}P_mP_n\,dx\) を Gauss–Legendre 求積で計算せよ。対角が \(2/(2k+1)\) に、非対角が機械精度でゼロになることを数値で示せ。

    (c) \(f(x)=|x|\) と \(g(x)=\sin 3x\) の Legendre 展開係数

    \[ c_k=\frac{2k+1}{2}\int_{-1}^{1}f(x)P_k(x)\,dx \]

    を \(k\le40\) まで求め、\(|c_k|\) の減衰の速さを比べよ。また \(M\) 次までの部分和の \(L^2\) 誤差を \(M=4,8,12,16,20\) で測り、両者の違いが本文の「係数の減衰は関数の滑らかさを映す」で説明できることを述べよ。

    ヒント
    • (a) \(\langle x^m,x^n\rangle=\int_{-1}^{1}x^{m+n}dx\) は \(m+n\) が奇数なら \(0\)、偶数なら \(2/(m+n+1)\) である。奇偶が違う組は最初から直交しているので、引く項はごくわずかしかない。
    • (b) \(P_mP_n\) は高々 \(16\) 次なので、\(2n-1\ge16\) すなわち \(9\) 点以上の Gauss 求積で厳密になる。余裕をみて leg.leggauss(12) でよい。\(P_k\) の値は leg.legval(x, np.eye(K+1)[k]) で得られる（第 \(k\) 成分だけ \(1\) の係数ベクトルを渡す）。
    • (c) 積分は同じく Gauss 求積で。\(40\) 次までの係数まで見るので節点は多めに（leggauss(400) 程度）取る。片対数ではなく 両対数 で \(|c_k|\) をプロットすると、\(|x|\) 側が直線になる。np.polyfit(np.log(k), np.log(|c_k|), 1) で傾きを測るとよい（\(|x|\) は偶関数なので奇数次は \(0\)。傾きは偶数次だけで測る）。

    演習2（基礎）：Gauss 求積と台形則

    (a) \(n=2\) の Gauss–Legendre 公式について、節点が \(P_2(x)=\frac{1}{2}(3x^2-1)\) の零点 \(x=\pm1/\sqrt3\)、重みがともに \(w=1\) であることを使い、\(1,\ x,\ x^2,\ x^3\) の積分が 厳密 に得られることを手計算で確かめよ。\(x^4\) ではどうなるか。

    (b) \(\displaystyle\int_{-1}^{1}e^{-x^2}dx=\sqrt{\pi}\,\mathrm{erf}(1)\) を、Gauss–Legendre 求積と台形則で 同じ節点数 で計算し、\(n=2,4,6,8,10,12\) での誤差を比べよ。

    (c) \(\displaystyle\int_{0}^{1}\sqrt{x}\,dx=\frac{2}{3}\) を Gauss 求積で計算せよ。(b) のような速い収束は起きるか。起きない場合はその理由を述べ、変数変換 \(x=t^2\) によって収束が回復することを確かめよ。

    ヒント
    • (a) 対称な節点・等しい重みなので、奇数次は自動的に \(0\) になる。確かめるべきは \(m=0\) と \(m=2\)、そして破れる \(m=4\) である。
    • (b) 台形則は np.trapezoid(f(xt), xt)（xt = np.linspace(-1, 1, n)）で、Gauss と関数評価の回数をそろえる。\(\mathrm{erf}\) は from scipy.special import erf。
    • (c) 区間 \([0,1]\) へは \(x=(t+1)/2\)、\(dx=dt/2\) と写す。\(\sqrt{x}\) は \(x=0\) で導関数が発散する ── Gauss 求積が速いのは被積分関数が多項式でよく近似できるときだけだった、という点に戻って考えること。置換後の被積分関数が何次の多項式になるかを確かめよ。

    演習3（応用）：スペクトル法で境界値問題を解く

    本文の cheb_diff(N) を使い、Chebyshev 微分行列の性質と応用を調べる。

    (a) \(N=6\) の微分行列 \(D\) について、各行の和が \(0\) であることを確かめよ。また \(x^1,\ x^3,\ x^6,\ x^7\) を微分させ、どこまで厳密かを調べて理由を述べよ。

    (b) 境界値問題

    \[ u''(x)=e^{4x}\ \ \text{on}\ [-1,1], \qquad u(-1)=u(1)=0 \]

    をスペクトル法で解き、厳密解

    \[ u(x)=\frac{e^{4x}-x\sinh 4-\cosh 4}{16} \]

    との最大誤差を \(N=4,8,12,16,20,24\) で調べ、収束の様子を述べよ。

    (c) 同じ微分行列で 固有値問題 \(u''=\lambda u\)、\(u(\pm1)=0\) を解け。厳密な固有値は \(\lambda_m=-(m\pi/2)^2\)（\(m=1,2,\dots\)）である。\(N=16\) と \(N=32\) で先頭 \(8\) 個の固有値を比べ、「\(N+1\) 個の節点（うち内部節点は \(N-1\) 個）で信頼できるのは低次の何個までか」を数値から見積もれ。

    ヒント
    • (a) 行和が \(0\) になるのは対角成分をそう決めたからである。\(D\) は「\(N+1\) 点を通る \(N\) 次補間多項式を微分する」操作なので、厳密になる次数には上限がある。
    • (b) 離散化は \(D^2\mathbf u=\mathbf f\)。境界条件は \(0\) 行目と \(N\) 行目を単位行に置き換えて課す（cheb_diff の節点は \(x_0=+1\) から \(x_N=-1\) へ 降順 に並ぶことに注意）。\(N\) を上げすぎると丸め誤差で頭打ちになる。
    • (c) 境界値 \(u_0=u_N=0\) が既知なので、\(D^2\) の 内部節点だけの小行列 (D @ D)[1:N, 1:N] の固有値を求めればよい。np.linalg.eigvals は複素数を返すので .real を取り、降順に並べ替えて \(m\) の小さい順に対応させる。
