    演習1：のこぎり波のフーリエ係数

    周期 \(2\pi\) の のこぎり波 \(f(x) = x \quad (-\pi < x < \pi)\) を周期的に延長した関数を考える。

    (a) \(f\) の対称性（偶関数・奇関数）を述べ、フーリエ係数 \(a_n, b_n\) を手計算で求めよ。

    (b) 部分和 \(S_N(x)\) を Python で計算し、\(N=3, 10, 50\) で元ののこぎり波に重ねて描け。

    ヒント
    • のこぎり波は奇関数なので \(a_n=0\)。\(b_n=\frac{1}{\pi}\int_{-\pi}^{\pi}x\sin nx\,dx=\frac{2}{\pi}\int_{0}^{\pi}x\sin nx\,dx\)。
    • 部分積分 \(\int x\sin nx\,dx = -\frac{x\cos nx}{n}+\frac{\sin nx}{n^2}\) を使う。
    • \(\cos n\pi=(-1)^n\) に注意。
    • 周期延長は np.mod(x + np.pi, 2*np.pi) - np.pi で \([-\pi,\pi)\) に折り返せる。
