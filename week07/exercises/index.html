    演習1：畳み込み定理

    2 つの信号

    \[ f(t)=e^{-3t},\qquad g(t)=e^{-t}\qquad(t\ge 0) \]

    の畳み込み \((f*g)(t)\) を考える。

    (a) 畳み込みの定義 \((f*g)(t)=\displaystyle\int_0^t f(\tau)\,g(t-\tau)\,d\tau\) にしたがって、\((f*g)(t)\) を手計算で求めよ。

    (b) (a) の結果をラプラス変換すると \(F(s)G(s)\) に一致することを、sympy で確かめよ。

    (c) 畳み込み積分を使わずに、\(s\) 領域で \((f*g)(t)\) を求める手順を述べよ。

    ヒント
    • \((f*g)(t)=\displaystyle\int_0^t e^{-3\tau}e^{-(t-\tau)}\,d\tau=e^{-t}\int_0^t e^{-2\tau}\,d\tau\)。
    • \(F(s)=\dfrac{1}{s+3}\)、\(G(s)=\dfrac{1}{s+1}\)。積は \(\dfrac{1}{(s+1)(s+3)}\)。
    • sympy：本文の畳み込みのコードで、f と g を差し替える。

    演習2：初期値定理・最終値定理

    ある信号のラプラス変換が、次の式で与えられている。

    \[ F(s)=\frac{s+6}{s(s+2)} \]

    (a) 初期値定理と最終値定理で、\(f(0^+)\) と \(\displaystyle\lim_{t\to\infty}f(t)\) を逆変換せずに求めよ。

    (b) \(F(s)\) を部分分数に分けて逆変換し、\(f(t)\) を求めよ。(a) の値と一致することを確かめよ。

    (c) この \(F(s)\) に最終値定理を使ってよい理由を述べよ。

    ヒント
    • \(sF(s)=\dfrac{s+6}{s+2}\)。\(s\to\infty\) と \(s\to0\) の極限をとる。
    • \(\dfrac{s+6}{s(s+2)}=\dfrac{A}{s}+\dfrac{B}{s+2}\) の両辺に \(s(s+2)\) を掛け、係数を比べて \(A\) と \(B\) について解く。
    • 最終値定理の条件：\(sF(s)\) の極がすべて左半面にあること。

    演習3：伝達関数によるステップ応答

    次の系に、零状態（\(y(0)=y'(0)=0\)）からステップ入力 \(x(t)=u(t)\) を加える。

    \[ y''+2y'+5y=x(t) \]

    (a) 伝達関数 \(H(s)=Y(s)/X(s)\) を求めよ。極の位置から、不足制動・臨界制動・過制動のどれかを答えよ。

    (b) 最終値定理で定常値 \(\displaystyle\lim_{t\to\infty}y(t)\) を逆変換せずに求め、DC 利得 \(H(0)\) に等しいことを確かめよ。

    (c) \(Y(s)=H(s)/s\) を逆変換して \(y(t)\) を求め、solve_ivp の数値解と一致することを確かめよ。

    ヒント
    • 零状態で変換すると \((s^2+2s+5)Y=X\)。極は \(s^2+2s+5=0\) より \(s=-1\pm2i\)。
    • 左辺を 2 次系の形と比べ、\(\omega_n^2=5\)、\(2\zeta\omega_n=2\) から \(\omega_n\) と \(\zeta\) を求める。
    • 数値解は rhs = [z[1], 1.0 - 2*z[1] - 5*z[0]]（入力 \(x=1\)）、初期値 [0, 0]。
