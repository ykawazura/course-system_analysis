    逆ラプラス変換と s 平面

    前ページでは時間領域からラプラス変換 \(F(s)\) を求めた。本ページでは逆向き ── \(F(s)\) から時間関数 \(f(t)\) に戻す 逆ラプラス変換 を扱う。これを \(\mathcal{L}^{-1}[F(s)]\) と書く。実用上の鍵は 部分分数分解 であり、その背後にある s 平面の極 が時間応答を決める。最後に、この道具立てで 微分方程式を解く。

    逆変換は部分分数分解で

    システム解析で現れる \(F(s)\) はたいてい \(s\) の有理関数（多項式 ÷ 多項式）なので、これを 部分分数 に分け、各項を変換対の表（前ページ）で時間関数に戻せばよい。逆変換を与える複素積分もあるが、本講義では使わない。

    分子の次数が分母の次数より真に小さい有理関数を 厳密プロパー（strictly proper）という。本講義はこれを扱う。分子の次数が分母以上だと、割り算で出る多項式の部分が \(\delta(t)\) などになり、ふつうの関数に収まらない。

    \[ \frac{s}{s+1}=1-\frac{1}{s+1}\ \leftrightarrow\ \delta(t)-e^{-t} \]

    例として \(F(s)=\dfrac{s+3}{(s+1)(s+2)}\) を考える。部分分数に分けると

    \[ \frac{s+3}{(s+1)(s+2)}=\frac{2}{s+1}-\frac{1}{s+2} \]

    表の \(\dfrac{1}{s+a}\leftrightarrow e^{-at}\) と線形性から、

    \[ f(t)=2e^{-t}-e^{-2t} \]

    分母の因子 \((s+1)\), \((s+2)\) が、時間関数の \(e^{-t}\), \(e^{-2t}\) を生む（次節で「極」として扱う）。

    sympy で確かめる。

    def Linv(F):
    return sp.expand(sp.inverse_laplace_transform(F, s, t))

F = (s + 3) / ((s + 1) * (s + 2))
print("部分分数:", sp.apart(F, s))
print("逆変換  :", Linv(F))

    部分分数: -1/(s + 2) + 2/(s + 1)
逆変換  : 2*exp(-t) - exp(-2*t)

    sp.apart が部分分数分解を行う。関数 Linv は inverse_laplace_transform で逆変換し、expand で指数関数の和に展開して返す（sp.simplify で整理すると (2*exp(t) - 1)*exp(-2*t) のような積の形になる）。手計算の \(2e^{-t}-e^{-2t}\) と一致する。Linv は、後の微分方程式の解と演習でも使う。

    s 平面の極と時間応答

    有理関数 \(F(s)=\dfrac{N(s)}{D(s)}\) を、\(N\) と \(D\) の共通因子を約分した 既約形 にしてから、分母 \(D(s)=0\) の根を極（pole）、分子 \(N(s)=0\) の根を 零点（zero） という。約分が要るのは、たとえば \(\dfrac{s+1}{s+1}=1\) の \(s=-1\) が極でも零点でもないからである。極 \(s=p\) は時間領域の \(e^{pt}\) に対応する。応答の振る舞いは、ほぼ極の位置だけで決まる。第1回の「固有値 \(\lambda\) が \(e^{\lambda t}\) の形で振る舞いを決める」と同じ見方である。

    実極

    実数の極 \(s=p\) は \(e^{pt}\) を生む。\(p<0\) なら減衰、\(p>0\) なら発散する。減衰率 は \(-p\) である（\(p\) そのものは指数の増大率）。たとえば極 \(-1\), \(-2\) をもつ \(2e^{-t}-e^{-2t}\) では、減衰率の大きい \(e^{-2t}\) の項が先に消える。

    複素共役の極対

    \(F(s)\) の係数が実数なら、複素数の極は共役の対 \(s=-\sigma\pm i\omega\) で現れる。2 つの項をまとめると

    \[ e^{(-\sigma+i\omega)t},\ e^{(-\sigma-i\omega)t} \ \longrightarrow\ e^{-\sigma t}\cos(\omega t+\phi) \]

    となる。ここでの \(\sigma\) は減衰率（正の数）で、極の実部は \(-\sigma\) である。対の 2 項の係数も共役 \(c\), \(\bar c\) になり、\(c\,e^{i\omega t}+\bar c\,e^{-i\omega t}=2\lvert c\rvert\cos(\omega t+\phi)\)（\(\phi=\arg c\)）となる。

    実部 \(-\sigma\) が減衰率 \(\sigma\) を、虚部 \(\omega\) が 角周波数 [rad/時間] を与える。単位時間あたりの振動の回数は \(\omega/(2\pi)\) [cycle/時間] である。

    重極

    既約形の分母が \((s-p)^m\) を因子にもつとき、\(p\) を \(m\) 重極 という（\(m=1\) なら 単純な極）。このとき \(e^{pt}\) だけでなく、\(t^{m-1}e^{pt}\) までの項が現れる。たとえば表の \(t\leftrightarrow 1/s^2\) に s 推移を使うと、

    \[ t\ \leftrightarrow\ \frac{1}{s^2} \quad\xrightarrow{\ \text{s 推移}\ }\quad t\,e^{-t}\ \leftrightarrow\ \frac{1}{(s+1)^2} \]

    となり、\(s=-1\) の 2 重極が \(te^{-t}\) を生む。\(t\) 倍が付くが、\(e^{-t}\) のほうが速く小さくなるので減衰する。

    極の位置とインパルス応答

    極が複素平面のどこにあるかで、応答が分類できる。

    \(F(s)\) をシステムの性質を表す式とみると、その逆変換 \(h(t)\) が第4回のインパルス応答にあたる。詳細は第7回で扱う。

    極の位置と「安定性」

    すべての極が 左半面（\(\operatorname{Re}(s)<0\)） にあれば、応答は時間とともに \(0\) へ減衰する ── これを（漸近）安定 という。1 つでも右半面に極があれば発散する。これを 不安定 という。右半面に極がなく、虚軸上の極が すべて単純（1 重） な場合が境界のケースで、減衰も発散もしない 持続振動 となる。これを 限界安定 という。

    ここで「単純」という条件は落とせない。虚軸上に 重極 があると振幅は発散する。たとえば \(\dfrac{1}{(s^2+1)^2}\) の逆変換は \(-\dfrac{t\cos t}{2}+\dfrac{\sin t}{2}\) で、\(t\cos t\) の項が増え続ける。虚軸上に極があるだけで持続振動と決めつけてはいけない。

    さらに、入力に対する BIBO 安定（有界な入力に有界な出力）では基準がもっと厳しく、虚軸上の極は単純であっても不安定 と判定される。実際 \(\dfrac{1}{s^2+1}\) の系に共振する入力 \(\sin t\) を入れると出力は発散する。漸近安定・限界安定・BIBO 安定の厳密な区別は第8回で整理する。この「極の位置で安定性が決まる」という見方は、第8回の応用（制御・安定判別）の中心テーマになる。

    ラプラス変換で微分方程式を解く

    ここまでの道具 ── 微分の公式（前ページ）と 部分分数による逆変換 ── だけで、微分方程式が機械的に解ける。微分方程式 → 代数方程式 → 部分分数 → 逆変換 の順に進む。例として次の初期値問題を解く。

    \[ y''+3y'+2y=0,\qquad y(0)=1,\quad y'(0)=0 \]

    未知関数 \(y(t)\) の変換を \(Y(s)=\mathcal{L}[y(t)]\) と書く。

    手順 1：両辺をラプラス変換する。 微分の公式 \(\mathcal{L}[y']=sY-y(0)\)、\(\mathcal{L}[y'']=s^2Y-sy(0)-y'(0)\) に初期値を入れると、

    \[ \bigl[s^2Y-s\cdot1-0\bigr]+3\bigl[sY-1\bigr]+2Y=0 \]

    となる。初期値 \(y(0)=1\), \(y'(0)=0\) は、この段階で式に入る。右辺の \(0\) の変換は \(0\) である（線形性）。

    手順 2：\(Y(s)\) について解く。

    \[ (s^2+3s+2)\,Y=s+3 \quad\Longrightarrow\quad Y(s)=\frac{s+3}{(s+1)(s+2)} \]

    微分方程式が、\(Y\) の 1 次の 代数方程式 になった。これは先に部分分数で逆変換した \(F(s)\) と同じ式である。分母 \(s^2+3s+2\) の根 \(-1\), \(-2\) は、この方程式を状態方程式 \(\dot{\mathbf{x}}=A\mathbf{x}\) に書き直したときの行列 \(A\) の固有値に一致する（詳細は第8回・第11回）。

    手順 3：部分分数に分けて逆変換する。

    \[ Y(s)=\frac{2}{s+1}-\frac{1}{s+2} \quad\Longrightarrow\quad y(t)=2e^{-t}-e^{-2t} \]

    検算すると、\(y(0)=2-1=1\)、\(y'(t)=-2e^{-t}+2e^{-2t}\) より \(y'(0)=0\) で、初期条件を満たす。極 \(-1\), \(-2\) がそれぞれ \(e^{-t}\), \(e^{-2t}\) を生む。どちらも左半面にあるので解は減衰する。

    時間領域の微分方程式が、\(s\) 領域では ただの代数方程式 になった点に注目してほしい。これがラプラス変換の威力である。

    sympy で解く

    手順 2・3 を sympy に解かせる。

    Y = sp.symbols("Y")
Ys = sp.solve(sp.Eq((s**2 + 3*s + 2) * Y, s + 3), Y)[0]
print("Y(s) =", Ys)
print("ラプラス解 y(t) =", Linv(Ys))

    Y(s) = (s + 3)/(s**2 + 3*s + 2)
ラプラス解 y(t) = 2*exp(-t) - exp(-2*t)

    sp.Eq(左辺, 右辺) は等式「左辺 \(=\) 右辺」を表す。手順 2 の方程式をこれで作る。前ページ の「sympy の使い方」の sp.solve(f, x) は \(f=0\) を解いた。右辺が \(0\) でない方程式は、このように sp.Eq で等式にして sp.solve に渡す。Python の = は代入、== は 2 つの式が同じ形かどうかの判定（True／False を返す）なので、どちらも等式の代わりにはならない。sp.solve で \(Y\) について解き、解のリストの 1 つ目（ここでは唯一の解）を [0] で取り出す。Linv で時間領域に戻す。

    出力の \(Y(s)\) と \(y(t)\) は、手順 2・3 の手計算と一致する。\(Y(s)\) は、手順 2 の式の分母を展開した形 \(\dfrac{s+3}{s^2+3s+2}\) で表示されている。

    solve_ivp と比べる

    得られた解を、数値積分（scipy.integrate.solve_ivp）と比べて検証する。\(y''=-3y'-2y\) を、\(z=[y,\ y']\) の 1 階の連立系に直して数値積分する（第1回と同じ）。

    import numpy as np
from scipy.integrate import solve_ivp

def rhs(tt, z):           # z = [y, y']
    return [z[1], -3*z[1] - 2*z[0]]
tm = np.linspace(0, 6, 7)
num = solve_ivp(rhs, [0, 6], [1.0, 0.0], t_eval=tm,
                rtol=1e-10, atol=1e-12).y[0]
ana = 2*np.exp(-tm) - np.exp(-2*tm)
print("最大誤差:", f"{np.max(np.abs(num - ana)):.2e}")

    最大誤差: 1.99e-12

    rtol, atol は相対・絶対の許容誤差である。tm の 7 点で、数値解 num と解析解 ana の差の最大を測る。

    ラプラス変換による解析解と数値積分が、\(\sim10^{-12}\) の範囲で一致する。この差は丸め誤差ではなく 数値積分（時間刻みを有限個に区切ったこと）による誤差 で、許容誤差の指定で大きさが変わる。上のコードで atol=1e-12 のまま rtol だけを変えると、最大誤差は rtol=1e-3（solve_ivp の既定値）で 2.39e-05、1e-6 で 4.29e-08、1e-10 で 1.99e-12 と、指定した許容誤差に応じて素直に小さくなる ── 解析解があるからこそ、こうして数値解の精度そのものを測ることができる。

    まとめ

    • 逆変換 \(\mathcal{L}^{-1}\) は部分分数分解と表で求める（sympy.apart／inverse_laplace_transform）。
    • 有理関数 \(F(s)=N/D\) の 極 \(p\)（既約形にしたうえで \(D=0\) の根）が \(e^{pt}\) を生む。左半面なら減衰（安定）、右半面なら発散、虚軸上の単純な極なら持続振動。実極は減衰／発散、複素共役の極対は（減衰）振動、\(m\) 重極は \(t^{m-1}e^{pt}\) までを生む。減衰率は \(-\operatorname{Re}(p)\)、角周波数は \(\lvert\operatorname{Im}(p)\rvert\)。
    • 虚軸上の重極は発散するので、虚軸上に極があるだけで持続振動と決めつけない。
    • 微分方程式 → 代数方程式 → 部分分数 → 逆変換 で初期値問題が解ける。\(y''+3y'+2y=0\) の解 \(2e^{-t}-e^{-2t}\) は solve_ivp と一致する。

    本講義との接続

    本回では入力のないシステム（自由応答）を扱った。第7回 では 畳み込み積分 と各種公式を整え、入力 \(X(s)\) と出力 \(Y(s)\) を結ぶ 伝達関数 \(H(s)=Y(s)/X(s)\) を導入する（第4回でフーリエ領域の積として見た「フィルタ」の一般化）。第8回 では極の位置から 安定性 を判定し、過渡応答・制御へ応用する。s 平面の極という見方は、これらすべての土台になる。
