    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    AI の利用について

    演習のコードは AI（ChatGPT・Claude・Gemini など）に書かせてよい。ただし 生成されたコードは全ての行に目を通し、各ステップが何をしているのかを理解すること。講義の最後に演習の時間が取れた回に、自分のコードを解説してくれた人はプラス評価する。理解せずに提出したコードは自分の力にならない。

    環境

    Python（numpy, matplotlib）を使う。DMD は既成のライブラリを使わず、講義ノートに載せた \(10\) 行の dmd 関数を自分で書いて使うこと。必要なのは numpy.linalg（svd, eig, lstsq, qr）だけである。環境は第1回の Google Colab または ローカル環境 を参照。

    演習1（基礎）：DMD による線形系の固有値復元

    \(3\) 次元の離散系 \(z_{k+1}=A_0z_k\) を考える。

    \[ A_0=\begin{pmatrix} 0.9&0&0\\ 0&0.8\cos\tfrac{\pi}{6}&-0.8\sin\tfrac{\pi}{6}\\ 0&0.8\sin\tfrac{\pi}{6}&0.8\cos\tfrac{\pi}{6} \end{pmatrix} \]

    \(z_0=(1,1,0)^\top\) から \(40\) 点を生成し、np.linalg.qr で作った \(150\times3\) の直交行列 \(Q\) で \(x_k=Qz_k\) と埋め込んだものを観測データ \(X\)（\(150\times40\)）とする。標本化間隔は \(\Delta t=0.05\) とする。

    (a) \(X\) に DMD を適用し、\(r=1,2,3,5\) のそれぞれで得られる \(\lambda\) を \(A_0\) の真の固有値と比べよ。\(X_1\) の特異値スペクトルから \(r\) をどう決めればよいかを述べよ。また \(r\) が足りないとき、残った固有値は真の固有値の「一部」になっているかどうかを確かめよ。

    (b) 同じ系を \(\Delta t=0.15\) で標本化したデータ（\(A_0\) の代わりに \(A_0^3\) を使えばよい）を作り、\(\lambda\) は \(\Delta t\) によって変わるのに \(\omega=\log\lambda/\Delta t\) は変わらないことを数値で確かめよ。\(\omega\) の \(3\) つの値がそれぞれ何を意味するかを述べよ。

    (c) 観測データに時間によらない定数ベクトル \(c\)（各成分は \(\mathcal N(0,1)\) の乱数）を加えて \(X+c\mathbf 1^\top\) とすると、\(r=3\) の DMD は真の固有値を復元できなくなる。理由を述べ、\(r\) をいくつにすれば復元できるかを数値で確かめよ。そのとき増えたモードの \(\lambda\) はいくつになるか。

    ヒント
    • (a) 真の固有値は np.linalg.eigvals(A0) で得られる。\(r\) が真のランクより小さいと、\(U_r\) の張る空間が \(A\) の不変部分空間にならない。そこへ射影した \(\tilde A\) の固有値が、真の固有値の部分集合になる保証はどこにもない。逆に \(r\) を真のランクより大きく取ると、S[:r] に \(10^{-16}\) 程度の特異値が入り、それで割った成分が結果を汚す。
    • (b) \(\Delta t\) を \(3\) 倍にすることと、\(1\) ステップで \(3\) ステップぶん進む行列 \(A_0^3\) を使うことは同じである。\(A_0^3\) の固有値は \(A_0\) の固有値の \(3\) 乗になる。
    • (c) \(x_k=Qz_k+c\) を漸化式に入れてみよ。\(x_{k+1}=Ax_k\) の形にするには、\(c\) 自身が「時間で変化しないモード」として仲間に入る必要がある。時間で変化しないとは \(\lambda\) がいくつのことか。

    演習2（基礎）：2 モードデータの分離と \(\omega\) の同定

    空間 \(x\in[0,2\pi)\) を \(100\) 点（endpoint=False）、時間 \(t\in[0,10]\) を \(60\) 点で離散化し、次の複素の場を作る。

    \[ u(x,t)=g_1(x)e^{(-0.2+3i)t}+0.25\,g_2(x)e^{(0.1+8i)t} \]

    ここで \(g_1(x)=e^{-(x-2)^2}\)、\(g_2(x)=e^{-(x-3)^2}\) である。\(2\) つの空間形状は互いに重なりを持ち、直交していない。

    (a) \(r=2\) の DMD を適用し、得られる \(\omega\) を真の値 \(-0.2+3i\)、\(0.1+8i\) と比べよ。また各 DMD モードの空間形状が \(g_1,g_2\) とどれだけ一致するかを、向きだけを見る量 \(|\langle\phi,g\rangle|/(\lVert\phi\rVert\lVert g\rVert)\) で評価せよ。

    (b) 同じデータに POD（np.linalg.svd）を適用し、上位 \(2\) 本の POD モードと \(g_1,g_2\) との一致度を求めよ。さらに POD の時間係数 \(v_1(t),v_2(t)\) をフーリエ変換し、全パワーのうち \(\omega\simeq3\) と \(\omega\simeq8\) の付近に入る割合をそれぞれ求めよ。DMD の結果と食い違う理由を説明せよ。

    (c) 時刻を \(2,4,6\) 個おきに間引いて \(\Delta t\) を粗くし、それぞれで \(r=2\) の DMD を適用せよ。\(\omega=8\) が正しく同定できなくなるのはどの \(\Delta t\) からか。またそのとき得られる値が \(8-2\pi/\Delta t\) と一致することを確かめよ。

    ヒント
    • (a) データは複素数なので、dmd の中の conj() が効いてくる。ランクは \(2\) である（実の \(\cos\) ではなく複素指数を使っているので、\(1\) つのモードにつき固有値は \(1\) 個）。
    • (b) POD モードは互いに直交するように作られるが、真の \(g_1,g_2\) は直交していない。直交する \(2\) 本で直交しない \(2\) 本を張ろうとすれば、どちらのモードにも両方が混ざる。スペクトルは np.fft.fft と np.fft.fftfreq(nt, dt)*2*np.pi で角周波数の格子を作れば読める。パワーは振幅の \(2\) 乗である。
    • (c) ナイキスト角周波数は \(\pi/\Delta t\) である。\(\Delta t\) を \(k\) 倍に粗くすれば上限は \(1/k\) 倍になる。折り返しは \(\omega\) から \(2\pi/\Delta t\) を引く操作である。

    演習3（応用）：雑音下のランク選択と予測の限界

    演習2 と同じ場 \(u(x,t)\)（\(100\times60\)、ランク \(2\)）を使う。雑音は複素の白色雑音とし、実部・虚部それぞれの標準偏差を \(\sigma/\sqrt2\) とする。このとき \(\sqrt{\mathrm E\lvert z\rvert^2}=\sigma\) になる（\(\lvert z\rvert\) の標準偏差そのものは \(\sigma\sqrt{1-\pi/4}\simeq0.463\sigma\) で、\(\sigma\) とは別の量である。以下で「雑音の大きさ \(\sigma\)」というのは前者を指す）。

    (a) \(\sigma=0.02,\ 0.1,\ 0.5\) の雑音を加えたデータについて、\(X_1\) の特異値を対数軸で描け。雑音床の目安 \(\sigma(\sqrt m+\sqrt n)\)（\(m,n\) は \(X_1\) の行数・列数）と実測の \(\sigma_3\) を比べ、それぞれの場合に信号のモードが見分けられるかを述べよ。

    (b) \(\sigma=0.1\) のデータで \(r=1,2,6,20\) の DMD を実行し、雑音を加える前の 真の場との再構成誤差 \(\lVert D-D_r\rVert_F/\lVert D\rVert_F\) と、真の \(\omega\)（\(-0.2+3i\)、\(0.1+8i\)）からの最大のずれを求めよ。ランク不足と過剰のどちらがより危険かを、数値を挙げて論じよ。

    (c) 先頭 \(24\) 枚（\(40\%\)、\(t\le3.90\)）だけで DMD を学習し、残りを予測させたときの時刻ごとの相対誤差を、次の \(2\) つのデータについて比較せよ。

    • (i) 演習2 の場（雑音なし）── 指数関数の有限和で厳密に書ける
    • (ii) 片方のモードの振幅が飽和する場（雑音なし） \(u_s(x,t)=g_1(x)e^{3it}/(1+e^{-(t-5)})+0.25\,g_2(x)e^{8it}\)

    (ii) で何が起きるかを \(\mathrm{Re}\,\omega\) の最大値から説明し、学習区間を飽和後（\(t\ge7.12\)、すなわち t[42] 以降＝\(43\) 番目以降）に取り直すと結果がどう変わるかを確かめよ。

    ヒント
    • (a) \(X_1\) は \(100\times59\) である。特異値は np.linalg.svd(Xn[:, :-1], compute_uv=False)、対数軸は plt.semilogy。ランクが \(2\) なので、見るべき段差は \(\sigma_2\) と \(\sigma_3\) の間である。
    • (b) 再構成は \(D_r=\Phi\,\mathrm{diag}(b\lambda^k)\)（複素のまま）で、比較の相手は雑音入りではなく真の場である。\(\omega\) のずれは、真の \(2\) つそれぞれについて「最も近い DMD の \(\omega\) との距離」を測り、その最大値を取る。
    • (c) 学習は dmd(Dat[:, ns:ntr], dt, 2) で行い、再構成は \(k=0,\dots\) と学習開始時刻から数える。誤差は列ごとに np.linalg.norm(..., axis=0) で測ると時刻ごとの誤差が得られる。飽和するデータは指数関数の有限和では書けない。立ち上がりの途中だけを見た DMD が振幅の増加を何と解釈するかを考えよ。
