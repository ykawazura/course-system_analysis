    動作確認

    環境（Google Colab または ローカル環境）が正しく整ったことを、簡単な計算とグラフ描画で確認する。

    ステップ 1: ライブラリの確認

    新しいノートブック（またはセル）で次を実行する。

    import numpy as np
import scipy
import matplotlib
import matplotlib.pyplot as plt

print("NumPy      :", np.__version__)
print("SciPy      :", scipy.__version__)
print("Matplotlib :", matplotlib.__version__)

    バージョンがエラーなく表示されれば、必要なライブラリは揃っている。

    NumPy      : 1.26.4
SciPy      : 1.13.1
Matplotlib : 3.8.4

    （バージョン番号は環境によって異なってよい。）

    ステップ 2: 簡単な計算

    NumPy で配列の計算ができることを確認する。

    x = np.linspace(0, 2 * np.pi, 5)   # 0 から 2π を 5 点に分割
y = np.sin(x)
print("x =", np.round(x, 3))
print("sin(x) =", np.round(y, 3))

    x = [0.    1.571 3.142 4.712 6.283]
sin(x) = [ 0.  1.  0. -1. -0.]

    ステップ 3: グラフを描く

    最も簡単な「システムの出力」として、正弦波を描いてみる。u(t) を入力、y(t) を出力に見立てている。

    import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 2, 500)        # 時間 0〜2 秒
y = np.sin(2 * np.pi * 3 * t)     # 3 Hz の正弦波（システムの出力 y(t)）

plt.figure(figsize=(7, 3))
plt.plot(t, y, color="#1976D2")
plt.xlabel("time t [s]")
plt.ylabel("output y(t)")
plt.title("3 Hz sine wave")
plt.grid(True, alpha=0.3)
plt.show()

    3 Hz の正弦波（2 秒間で 6 周期）が描かれれば成功である。

    図をファイルに保存する

    plt.show() の代わりに plt.savefig("wave.png", dpi=150, bbox_inches="tight") とすると図を画像ファイルに保存できる。Colab では生成したファイルを ドライブにマウントして保存するか、files.download() で手元に落とせる。

    ステップ 4: SciPy で動的システムを解く（発展）

    動的システムと状態空間表現 で扱う減衰振動子を、SciPy の solve_ivp で解いてみる。状態空間表現（1 階の連立系）にしてあるので、そのまま数値積分できる。

    import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

m, c, k = 1.0, 0.4, 4.0
A = np.array([[0.0, 1.0],
              [-k / m, -c / m]])

def rhs(t, x):
    return A @ x

sol = solve_ivp(rhs, (0, 20), [2.5, 0.0],
                t_eval=np.linspace(0, 20, 1000), rtol=1e-9)

plt.figure(figsize=(7, 3))
plt.plot(sol.t, sol.y[0], color="#1976D2")
plt.xlabel("time t"); plt.ylabel("position x(t)")
plt.title("Damped oscillator")
plt.grid(True, alpha=0.3)
plt.show()

print("eigenvalues of A:", np.linalg.eigvals(A))

    減衰振動の波形が描かれ、固有値が -0.2 ± 1.99j（実部が負）と表示されれば、本講義の演習に必要な環境は完全に整っている。
