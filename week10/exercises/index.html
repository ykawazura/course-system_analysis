    演習1（基礎）：CWT による過渡の検出と周波数の同定

    サンプリング周波数 \(f_s=1000\) Hz、長さ 2 s の信号

    \[ x(t)=\sin(2\pi\cdot50\,t) +1.2\,\sin(2\pi\cdot200\,t)\,e^{-\left(\frac{t-1.2}{0.010}\right)^{2}} \]

    を考える。50 Hz の定常成分に、\(t=1.2\) s だけに現れる 200 Hz の短いバーストが重なっている。

    (a) 通常のフーリエ変換 np.fft.rfft の振幅スペクトルからピークを検出せよ。また信号を時間反転した x[::-1] の振幅スペクトルと比較し、バーストの時刻がスペクトルに残っていない ことを確かめよ。

    (b) 複素 Morlet ウェーブレット "cmor1.5-1.0" で CWT を計算し、120 Hz より高い側で \(|W(a,b)|\) が最大になる時刻と周波数を求めよ。バーストの真の時刻 1.200 s・周波数 200 Hz とどれだけ一致するか。

    (c) 50 Hz と 200 Hz それぞれのスケールについて \(|W|\) の時間変化を取り出し、「最大値の半分を超えている時間」を比べよ。50 Hz が持続的、200 Hz が過渡的であることを数値で示せ。

    ヒント
    • スケールは \(a=\dfrac{f_c f_s}{f}\)。\(f_c\) は pywt.central_frequency("cmor1.5-1.0")。
    • coef, fw = pywt.cwt(x, fc*fs/freqs, wav, sampling_period=1/fs) とすると、fw が各行の周波数 [Hz]、coef[i, j] が周波数 fw[i]・時刻 t[j] の係数。
    • 2 次元配列の最大値の位置は np.unravel_index(np.argmax(A), A.shape)。
    • ある周波数 \(f_0\) に最も近い行は A[np.argmin(np.abs(fw - f0))]。
    • 「半値を超える時間」は (row > row.max()*0.5).sum()/fs（秒）。

    演習2（応用）：ウェーブレット縮退による雑音除去

    \(n=2048\) 点の ドップラー信号

    \[ x(u)=\sqrt{u(1-u)}\,\sin\!\left(\frac{2\pi\cdot1.05}{u+0.05}\right), \qquad u\in[0,1) \]

    （最大値が 3 になるように正規化する）は、左端ほど速く振動し右へ行くほどゆっくりになる、典型的な非定常信号である。これに標準偏差 \(\sigma=0.3\) の白色雑音を加えた観測から、元の信号を復元する。

    (a) 雑音入り信号の SNR を \(10\log_{10}\dfrac{\sum x^2}{\sum(x-\hat x)^2}\) [dB] で求めよ。

    (b) pywt.wavedec(noisy, "sym8", level=6) で分解し、最細レベルの詳細係数から \(\hat\sigma=\dfrac{\operatorname{median}(|d_1|)}{0.6745}\)、ユニバーサルしきい値 \(\lambda=\hat\sigma\sqrt{2\log n}\) を求めよ。mode="hard" と mode="soft" の両方で縮退し、復元信号の SNR を比較せよ。

    (c) ハードしきい値で残った係数の個数 \(K\) を数え、同じ \(K\) 個 の上位フーリエ係数だけで作った近似の SNR と比べよ。差が出る理由を、ドップラー信号の性質と結びつけて考察せよ。

    ヒント
    • rng = np.random.default_rng(7) で乱数を固定すると、下の解答と同じ値が再現できる。
    • \(\hat\sigma\) の分母 \(0.6745\) は、標準正規分布の中央絶対偏差（MAD）である。
    • ct = [c[0]] + [pywt.threshold(d, thr, mode=mode) for d in c[1:]] のように、近似係数 c[0] にはしきい値をかけない（低周波の背景は残す）。
    • ソフトしきい値は \(|c|>\lambda\) の係数だけを符号を保ったまま \(\lambda\) だけ 0 に近づける（\(|c|\le\lambda\) は 0）。残る係数の位置はハードと同じでも、振幅が一律に \(\lambda\) だけ縮む。
    • pywt.wavedec は既定で信号の端を折り返して延長するので、係数の総数はもとの \(n\) より少し多くなる。[len(a) for a in c] を表示して確かめること。
    • フーリエ側は i = np.argsort(np.abs(X))[::-1][:K] で上位 \(K\) 個を選び、それ以外を 0 にして np.fft.irfft。
